# Sophon (智子)

Sophon 是一款基于 Kotlin Multiplatform 构建的现代 Android 桌面端开发辅助工具。它整合了 Android 开发者日常高频使用的各种调试能力，致力于作为开发过程中的超级助手，极大提升开发和调试效率。

## 1. 为什么需要这款 Android 桌面工具？

在日常的 Android 开发中，开发者经常需要在各种命令行工具（如 ADB）、不同的开发环境以及各种杂乱的脚本中频繁切换。这种碎片化的工作流不仅极大地打断了思路，还降低了整体的开发效率。

**Sophon 的使命就是打破这些开发壁垒：**
* **化繁为简**：将枯燥繁琐的命令行操作（如安装 APK、配置代理、分析性能等）转化为直观、易用的图形化界面，轻点鼠标即可完成。
* **一站式工作台**：集中管理多设备、多环境，无论是性能监控还是设备调试，全部在一个窗口内高效掌控，无需在不同窗口和终端中反复横跳。
* **零负担开箱即用**：降低开发配置成本，告别繁杂的路径与环境变量设置，即使是新手开发者也能迅速上手，将所有精力聚焦于代码与业务逻辑本身。
* **原生体验与极致性能**：区别于传统的 Web 包装方案，基于 KMP 和 Compose 构建的客户端体验极为流畅，在保证高性能运转的同时提供现代感十足的 UI 交互，让调试成为一种享受。

## 2. 核心技术栈

本项目完全拥抱 Kotlin 现代生态，使用了以下核心库和框架：

* **核心语言**: Kotlin 
* **架构模式**: Android Clean Architecture (遵循清晰的层级划分，业务逻辑与 UI、数据来源完全解耦)
* **UI 构建框架**: Compose Multiplatform (Compose for Desktop)
* **异步与事件驱动**: Kotlin Coroutines & Flow
* **路由与状态控制**: AndroidX Navigation Compose, ViewModel
* **本地数据持久化**: DataStore
* **数据解析**: kotlinx.serialization
* **设计规范**: Material Design 3

## 3. 核心功能介绍

作为 Android 开发者的瑞士军刀，Sophon 提供了极其丰富的调试与监控模块：

* **🤖 ADB 快捷操作集 (ADB Tools)**: 提供可视化的 ADB 指令面板，包括设备连接、快速重启、清理缓存等，无需手敲复杂命令。
* **📈 系统级监控 (System Monitor)**: 对设备全局的系统级资源（温度、CPU、相机等）进行实时追踪监控。
* **📊 应用监控 (App Monitor)**: 实时监控目标应用（指定包名）的线程信息、文件目录、任务栈、图形信息等内容。
* **🔗 DeepLink 调试器 (DeepLink)**: 快速发送和验证应用内的 DeepLink / URI Scheme，检查界面路由拉起是否准确符合预期。
* **🛠 开发者核心选项 (Developer Tools)**: 集成常用的 Android 开发者选项功能（如布局边界查看、动画缩放调整等），一键极速开关，无需在手机设置中深挖。
* **📱 设备信息管理 (Device Info)**: 直观且全面地展示已连接设备的详细硬件信息、系统版本、屏幕分辨率及网络 IP 状态。
* **🌍 国际化与本地化测试 (i18n)**: 针对多语言场景，为应用提供便捷的多语言集成。
* **📦 一键安装工具 (Install APK)**: 拖拽即可安装 APK，直接告别 `adb install`。
* **🌐 网络与代理配置 (Proxy Settings)**: 快速为连接的设备设置全局或应用级别的 HTTP/HTTPS 代理，为抓包测试和网络接口排查提供极大便利。

## 4. 突出特点

* **⚡️ 纯净轻量，响应极速**：由于底层基于 Kotlin 且直接针对桌面（JVM）编译运行，彻底舍弃了 Electron 等套壳方案带来的臃肿，享受极低内存占用与高首屏渲染速度。
* **✨ 现代化的 UI / UX 交互**：全面采用最新的 Material Design 3 设计规范，排版清爽现代，大幅减轻长时间高压开发带来的视觉疲劳。
* **🔄 双端逻辑共享机制**：基于 Kotlin Multiplatform 打造，底层核心逻辑、网络通信与状态管理在多端无缝复用，非常利于未来产品形态演进。
* **🧩 高度可扩展的模块化架构**：项目功能模块之间完全解耦。得益于标准化的架构以及内置的 **Agent Rules**，AI 编程工具可以快速、无缝地理解项目上下文与开发规范，准确生成符合标准的新功能代码。无论是通过纯手工编写还是 AI 辅助，当开发者有了新的调试痛点时，都能以极低的门槛将新的独立子功能快速接入到 Sophon 之中。
